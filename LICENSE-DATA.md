# Documentation, metadata and third-party data licensing

Original project documentation and original catalogue metadata are intended to be released under **Creative Commons Attribution 4.0 International (CC BY 4.0)** unless a file states otherwise.

Reference software in `src/` and `scripts/` is licensed under Apache-2.0 as described in `LICENSE`.

Third-party datasets, ontologies, extracts and derived products remain subject to their own licences, terms and attribution requirements. Inclusion of a source in `catalog/data_sources.yml` does not relicense it. Contributors must verify asset-specific conditions before acquisition, redistribution or publication.
