# Instructions for human and AI contributors

Before changing this repository:

1. Read `conductor/index.md`, `conductor/product.md`, `conductor/tech-stack.md` and `conductor/workflow.md`.
2. Read the active track's `spec.md` and `plan.md`.
3. Work only on a defined task, update its checkbox and make a focused Git commit.
4. Preserve provenance: every external datum must identify source, release/version, retrieval date, licence and transformation.
5. Never add participant-level, row-level, small-cell or controlled data to Git.
6. Distinguish observed data, derived parameters, modelled estimates and expert assumptions in every output.
7. Do not imply endorsement by a data custodian or partner without written confirmation.
8. Prefer open standards, portable code and analyses that can run behind a custodian firewall.

Where documents conflict, the active track specification governs the task; project-level Conductor context governs everything else.
