# Track 007 plan

## Phase 1 — Register the review

- [ ] Define questions, inclusion criteria, sources, search strings and screening process.
- [ ] Register the protocol and version the search strategy.
- [ ] Define initiative, dataset, software and standard extraction fields.
- [ ] Recruit patient/community and external methods reviewers.

## Phase 2 — Search and screen

- [ ] Search scholarly literature and cited infrastructures.
- [ ] Search GitHub, Zenodo, OSF and Hugging Face reproducibly.
- [ ] Search registry, genomic, burden, policy and standards ecosystems.
- [ ] Deduplicate, screen and document exclusions.

## Phase 3 — Analyse adjacency

- [ ] Compare scope, geography, diseases, data access, methods, outputs and maturity.
- [ ] Identify reusable components, candidate partners and conflicting mandates.
- [ ] Test each claimed area of novelty against the evidence.
- [ ] Build a data and platform white-space map.

## Phase 4 — Decide and publish

- [ ] Draft adjacency matrix and landscape report.
- [ ] Obtain external challenge and revise claims.
- [ ] Record proceed, narrow, combine, revise or stop decision.
- [ ] Update product, roadmap and partner tracks with the decision.
