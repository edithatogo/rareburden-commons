# Track 015 governance decision register (non-binding template)

This template is a repository-owned preparation aid. It does not constitute
an appointment, consultation, consent, partnership, or release decision. A
completed record requires the accountable body and evidence owner to provide
the missing evidence through the approved governance process.

## Decision record

| Field | Entry |
|---|---|
| Decision ID | `GOV-015-<date>-<sequence>` |
| Topic / scope | _Describe the narrow decision._ |
| Proposed state | `draft` / `requested` / `confirmed` / `declined` / `expired` |
| Affected groups and jurisdictions | _List explicitly; do not infer representation._ |
| Decision body | _Proposed body from `governance-015-reference.md`._ |
| Reserved authority | _What this body may decide and what remains out of scope._ |
| Conflicts declared | _Yes/no plus a linked approved record._ |
| Patient/community rights and remuneration | _Evidence or `pending`._ |
| Data-governance / Indigenous authority | _Evidence or `pending`._ |
| Scientific and engineering review | _Evidence or `pending`._ |
| Public claim allowed | _Exact wording, or `none`._ |
| Dissent / appeal route | _Named process; no private workaround._ |
| Correction / withdrawal path | _Trigger, owner role and immutable history reference._ |
| Evidence references | _Stable document, hash, or minutes identifier._ |
| Effective / expiry date | _Leave blank until approved._ |
| Disposition | `open` / `bounded` / `approved` / `rejected` |

## Minimum evidence rule

`confirmed` is valid only when a written agreement, approved minutes, or
public custodian statement is identified. A draft note, email approach,
meeting invitation, or agent observation must remain `proposed` or `requested`.
Missing representation, remuneration, conflicts, authority, or appeal
evidence makes the decision `open`; it must not be silently treated as assent.

## Bounded fallback

If a decision cannot be approved, record the unsupported capability removed
from scope, the remaining supported public/synthetic scope, an owner role, and
an expiry/revisit date. Never broaden geographic, policy, partnership, or
global claims to compensate for missing evidence.
