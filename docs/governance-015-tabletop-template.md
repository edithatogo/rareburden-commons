# Track 015 governance tabletop exercise (non-binding template)

This is a dry-run protocol for the proposed governance bodies. It is not a
meeting record and does not activate any body, authority, partnership, or
data access.

## Scenario cards

1. A custodian requests withdrawal of a source release after an aggregate
   output has been prepared.
2. A policy user asks to describe a country comparison as a global ranking.
3. A funder requests veto power over an unfavourable result.
4. A community reviewer identifies stigmatizing language in a patient-facing
   summary.
5. A node reports a disclosure risk in an otherwise valid export.

## Exercise record

For each card, record:

| Question | Required response |
|---|---|
| Who has reserved authority? | Body and role, not a person's name. |
| What is the immediate safe action? | Pause, narrow, withdraw, or correct. |
| What evidence is required? | Agreement, minutes, policy, or technical receipt. |
| What may be said publicly? | Exact bounded wording. |
| How are affected communities heard? | Voting route, remuneration, and dissent path. |
| What is the appeal/correction route? | Immutable record and accountable role. |
| What remains unresolved? | Gate ID and owner role. |

## Pass criteria for a future authorised exercise

- every scenario has a reserved decision body and escalation route;
- no participant-level or controlled data are used;
- patient/community authority and remuneration are explicit;
- withdrawal, correction, and dissent preserve history;
- partnership and endorsement language remains claim-state controlled;
- unresolved findings receive an owner, disposition, and revisit date.

The exercise passes only when an authorised facilitator records attendees,
conflicts, evidence references, decisions, dissent, and follow-up. This
repository template is preparation only.
