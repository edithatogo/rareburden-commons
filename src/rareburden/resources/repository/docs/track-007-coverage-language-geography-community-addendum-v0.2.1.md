# Track 007 coverage, language, geography and community-authority addendum

**Status:** repository-owned supplemental assessment; it does not freeze or
register protocol v0.2.0 and does not close an external gate.

The current evidence now has an explicit missingness matrix. The 144 live-only
records contain metadata language values, but those values may describe a
repository or resource rather than the language of the underlying work. The
480 Crossref expansion rows have no observed record-language or geography
value. The 13 institutional records are curated examples, not a geographic
census. No attributable patient/community authority or acceptable-use receipt
exists.

Accordingly, all coverage statements remain bounded to the indexed public
evidence sampled. Missing language, geography, community ownership or
accessibility is `unknown`/`not_assessable`, never absence, exclusion or
evidence of low relevance. Agent-panel findings and the repository owner’s
disposition are advisory/owner evidence only; they cannot substitute for
patient/community authority.

The next material search expansion requires protocol v0.2.1. It should add
country and regional public registries, non-English query families, nullable
self-described language/geography/community-governance fields, and a plain-
language accessible limitations summary. Each stratum must have its own
terms, request hashes, rate limits, retrieval window and reconciliation record.
Until then, the recommended disposition is `narrow_and_remediate`: retain the
bounded adjacency hypothesis and missingness matrix, while prohibiting global,
representative, community-authority, partnership and confirmed-novelty claims.
