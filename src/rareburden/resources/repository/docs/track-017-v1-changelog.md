# Track 017 bounded v1 changelog

**Status:** draft for the approved non-production v1 candidate. This is not a
stable release announcement and does not authorise a tag or publication.

## Added

- Role-based quickstart, methods, analyst, developer, node-operator,
  data-steward and release guidance.
- Synthetic/reference demonstrator workflows with explicit provenance and
  limitation language.
- Aggregate-only paediatric export and small-cell suppression guidance.
- Synthetic economic scenario and uncertainty-assurance documentation.
- Bounded readiness checks that reject authority, continuity and stable-release
  overclaims.
- An exact-candidate evidence index for the eventual release decision.

## Deliberately excluded

- Participant-level, controlled-access or otherwise non-redistributable data.
- Production deployment, service-level commitments and public API guarantees.
- Empirical population estimates, patient/community representation and global
  or country-comparative claims.
- Partnership, endorsement, custodian access and external governance claims.

## Pending before any stable release

The owner must review an immutable candidate and decide `release with bounded
exclusions`, `revise` or `stop`. Release authority must then authorise the
artefact set, publication must occur through the approved channel, and the
published artefacts must be independently rechecked against their hashes.
