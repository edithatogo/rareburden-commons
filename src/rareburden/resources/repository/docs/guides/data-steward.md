# Data steward guide

For every source or derived package, record the source release/version,
retrieval event, terms/licence state, checksum, transformation, privacy class,
retention, withdrawal/correction path and intended-use disposition. Separate
observed data, transformed parameters, modelled estimates and assumptions.

The [licence and acquisition policy](../licence-acquisition-policy.md),
[data access model](../data-access-model.md) and source catalogue are the
starting points. Public metadata do not prove redistribution rights or
custodian approval. Keep uncertain terms fail-closed and use manual
registration where a provider requires it.
