# Methods guide

The authoritative method boundaries are defined by the [public-data-first
protocol](../protocols/public-data-foundation.md), [requirements
traceability](../requirements-traceability.md), and [release
policy](../release-policy.md).

For every result, distinguish observed data, transformed parameters, modelled
estimates and assumptions. Report estimands, definitions, overlap handling,
uncertainty, transportability limits, missingness and intended-use
disposition. Synthetic fixtures exercise the method contracts but do not
establish empirical validity, clinical utility or global coverage.
