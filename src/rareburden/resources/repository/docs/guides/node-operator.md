# Node operator and custodian guide

The node design keeps sensitive records with their custodian: **link
estimates, not identities**. This repository currently provides synthetic
offline reference material and an operator checklist; it does not authorise a
real deployment or controlled-data pilot.

Before any pilot, the custodian must record the approved terms, permitted
queries, disclosure controls, retention/withdrawal rules, incident contacts,
backup/restore conditions and release boundaries. Missing or withdrawn inputs
must not be represented as zero or current data.

Use [the federated operator guide](../federated-node-004-operator-guide.md)
and [security/operations reference](../security-operations-016-reference.md)
for the bounded preparation. Stop at the documented gate when approval or
controlled data are unavailable.
