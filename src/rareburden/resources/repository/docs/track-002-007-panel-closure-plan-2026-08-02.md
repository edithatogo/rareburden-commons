# Tracks 002 and 007 panel closure plan

**Status:** repository preparation; source activation and v0.3.0 release remain
disabled.

## Blockers

Track 002 still needs exact source terms, production file/endpoint dispositions,
and scientific/data-governance decisions. Track 007 still needs protocol
registration, independent methods challenge, and patient/community
interpretation. Agent panels can assemble and challenge the packets, but cannot
be represented as source licensors, custodians, scientific authorities or
constituted community reviewers.

## Options

### Option A — joint evidence panels with separate gate receipts (recommended)

Run one methods/source panel and one governance/community panel, with at least
three perspectives each. Bind both packets to the same candidate commit and
evidence-manifest digest. Produce separate receipt requests for Track 002 exact
URL/file/release, hash, terms, redistribution, metric and denominator decisions,
and Track 007 protocol version, search strategy, screening/exclusions, challenge
findings and interpretation.

### Option B — separate specialist panels

Use a distinct panel for each source family and each Track 007 challenge lane.
This improves specialization but increases coordination and inconsistency risk.

### Option C — bounded continuation without closure

Keep Track 002 registration-only and Track 007 provisional. Publish no live
source-derived claims or final novelty conclusions. Use this when a qualifying
receipt or registration route is unavailable.

## Recommendation and contingencies

Proceed with Option A. If exact terms or stable endpoints cannot be verified,
defer that candidate and retain only metadata/hashes. If protocol registration
is unavailable, version and preserve the protocol locally while marking it
unregistered. If challenge findings conflict, retain dissent and narrow the
claim. If patient/community interpretation is unavailable, remove
harm-sensitive or partnership claims rather than treating panel output as
consent.

## Dependency sequence

1. Freeze the source inventory and Track 007 protocol/search revision.
2. Assemble hash-bound panel packets using the panel-review-packet schema.
3. Challenge exact endpoints, terms, estimands, denominators, eligibility,
   screening and exclusions.
4. Challenge redistribution, retention, withdrawal, harms, equity and
   interpretation.
5. Apply in-scope fixes and regenerate manifests and runtime assets.
6. Issue separate accountable receipt requests and keep each gate pending.
7. Activate only sources with qualifying terms/scientific/custodian decisions;
   keep Track 007 provisional until registration and challenge receipts exist.
8. Permit v0.3.0 only after both tracks satisfy their release gates or claims
   are explicitly removed.
