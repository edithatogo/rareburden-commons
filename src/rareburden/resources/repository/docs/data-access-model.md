# Data access and contribution model

The operational fail-closed rules for licence evidence and automated acquisition
are defined in the [licence and acquisition policy](licence-acquisition-policy.md).

## Purpose

Define what “accessible” means and minimise the additional request made of each organisation.

## Access classes

| Class | Definition | Typical contribution | Default project action |
|---|---|---|---|
| Open download/API | Reusable files or API under public terms | Ontology, aggregate statistics, population denominators | Ingest with licence and release metadata |
| Public web/registration | Public browsing or aggregate download after routine account/terms | Burden estimates, dashboards, source metadata | Register, download permitted outputs and preserve query parameters |
| Controlled research | Individual-level or detailed data in an approved secure environment | Phenotypes, outcomes, utilisation, costs, genomic fractions | Apply through normal institutional process; analyse in place |
| Federated partner | Custodian runs agreed code or query locally | Disclosure-controlled parameter estimates | Supply versioned package and output specification |
| New collection | Required variable does not exist | Patient/family, caregiver, household or service measures | Co-design and fund new collection under local governance |

## The ask ladder

Use the least burdensome request that can answer the estimand:

1. use an existing open source;
2. use an existing public aggregate output;
3. request clarification or a more detailed aggregate table;
4. request execution of a standard query or analytic package;
5. apply for approved secure access to specific variables;
6. establish a formal collaboration for repeated or complex analyses;
7. collect new data only when no adequate source exists.

## Minimum data request

Every approach to a custodian should state:

- the question and estimand;
- the minimum variables or aggregate parameters required;
- disease and coding definitions;
- population and period;
- proposed analysis location;
- disclosure and export plan;
- expected outputs and authorship/acknowledgement pathway;
- why public sources are insufficient;
- whether funding is available for local effort.

## Contribution modes

A source can contribute metadata without data, aggregate parameters without records, code execution without exports, or a controlled analysis with reviewed outputs. Participation is modular; no contributor must join every component of the initiative.
