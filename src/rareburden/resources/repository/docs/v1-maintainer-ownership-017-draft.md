# v1 maintainer and sustainability draft

**Status:** non-binding draft; no appointment, funding or institutional host is
created by this document.  
**Track:** 017-documentation-adoption-v1  
**Revision:** 2026-08-01

This draft defines the records required before stable v1. Names, contacts and
commitments must be supplied by accountable programme and governance bodies;
placeholders are not owners.

Before v1, the programme must decide support targets, security-fix policy,
backup/restore authority, correction and withdrawal procedure, succession
trigger, cost owner and funding horizon, and institutional host or a
time-limited interim-owner arrangement.

If primary and backup owners do not accept these responsibilities, release is
blocked. A bounded public/synthetic release may proceed only with an explicit
interim-owner expiry, reduced support promise and removal of controlled-data,
global or institutional-operation claims. This draft does not satisfy a v1
sustainability criterion.
