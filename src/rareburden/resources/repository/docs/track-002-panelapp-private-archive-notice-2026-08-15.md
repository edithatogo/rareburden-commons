# PanelApp bounded private archive notice

The private source archive preserves the five paginated current-panel listing
responses observed from the public PanelApp API on 2026-08-15. The listing
contains 433 distinct panel/version rows and is bound by a SHA-256 manifest.

PanelApp's December 2019 terms limit use to non-commercial, non-diagnostic
purposes absent a separate agreement, require acknowledgement of Genomics
England and identified contributors, and impose additional OMIM and Orphanet
conditions. This snapshot therefore remains private and must not support a
public raw mirror, diagnostic use or commercialised output.

An attempted per-version detail capture was stopped after the server returned
HTTP 429. Only 129 of 433 details were observed; those partial details are not
represented as a complete snapshot. Any continuation must be sequential,
resumable and respectful of the source's rate limit.
