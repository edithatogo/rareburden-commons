# Track 004 controlled-node pilot application (non-binding draft)

This draft is an evidence checklist, not an approval or activation request.

## Required decisions

- custodian, lawful basis, and data-governance authority;
- approved aggregate estimands and minimum-cell/differencing thresholds;
- node version, lockfile fingerprint, retention and withdrawal contact;
- security review, signing/attestation method, and incident escalation;
- patient/community review and export-review authority.

## Evidence package

- repository revision and lockfile fingerprint;
- synthetic reproducibility output and schema validation;
- threat model, operator guide, disclosure policy and correction procedure;
- planned run matrix, rollback/withdrawal test, and named reviewers.

No controlled execution, source acquisition, or release is implied until every
decision above is recorded by the relevant authority.
