# Track 004 export-review checklist (draft)

Before any synthetic or approved aggregate export, the reviewer records:

- repository revision, node/coordinator versions, and lockfile fingerprint;
- execution and policy identifiers, including any superseded execution;
- confirmation that every row passed participant-field rejection;
- suppression status for every cell and the configured minimum threshold;
- differencing/query-budget assessment for repeated or overlapping outputs;
- log scan confirming credentials and participant values are redacted;
- correction/withdrawal disposition and named approving authority.

The checklist is a review aid only. It does not lower thresholds or substitute for
custodian, patient/community, privacy, security, or scientific approval.
