# Markdown and research documentation style guide

- Begin each document with its purpose and status.
- Use sentence-case headings.
- Keep one authoritative definition and link to it rather than copying divergent versions.
- Add an accessible prose summary immediately before or after every Mermaid diagram.
- Use tables only when comparison benefits from a shared column structure.
- Write dates in ISO 8601 in machine-readable files and unambiguous long form in prose.
- Label proposals, assumptions and estimates explicitly.
- Reference primary and official sources where available.
