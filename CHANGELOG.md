# Changelog

All notable changes will be documented here. The project uses semantic versioning for software and independent version identifiers for protocols, schemas, source releases and analytic releases.

## [0.2.0] — 2026-07-19

### Added

- Gate-based roadmap from the foundation through stable v1.0.0.
- Complete 17-track Conductor portfolio with specifications, plans, metadata, dependencies, owners, review gates and target releases.
- Machine-readable roadmap and track-metadata JSON Schemas.
- Offline roadmap, dependency, release-assignment and track-integrity validation.
- Maturity model and blocking multi-domain v1 acceptance contract.
- Requirements traceability, testing strategy, release policy and programme risk register.
- Mermaid delivery, assurance, lifecycle and release-evidence designs.
- Formal reviews for the foundation and v1-delivery-system tracks.
- Python 3.11–3.13 continuous-integration matrix and dependency update configuration.

### Changed

- `make check` now validates the complete programme and includes linting.
- Repository safety scanning now works in both Git clones and clean source archives.
- Product, strategy, architecture and workflow documents now distinguish planned capabilities from implementation evidence.
- Package version advanced to 0.2.0 and supported Python floor lowered to 3.11.

### Known limitations

- Public-source acquisition adapters, semantic mappings, parameter ledger, burden engine, demonstrators and federated node runner are not yet implemented.
- Governance bodies and external partnerships remain proposed rather than constituted.
- No burden estimate is published by this release.

## [0.1.0] — 2026-07-18

### Added

- Conductor context-driven project structure and track management.
- Vision, mission, purpose, strategy and proposed governance.
- MoSCoW requirements baseline.
- Mermaid conceptual, federated-sequence and metadata architecture.
- Public-data-first and federated architecture decision record.
- Founding scientific protocol RBC-P001 v0.1.0.
- Fourteen-source access catalogue with JSON Schema validation.
- Python command-line validator, tests, safety checks and CI workflow.
- Contributor, conduct, security and licensing foundations.
